# 🐾 Black Panther // Wakanda 3D Developer Portfolio

An immersive, high-tech developer portfolio designed with a Black Panther / Wakanda cyberpunk aesthetic, featuring interactive 3D WebGL graphics, spatial audio cues, and responsive glassmorphism HUD interfaces.

Built by **Charan Kumar** — Software Developer.

---

## ⚡ Tech Stack

- **Core**: React 19, TypeScript, Vite
- **3D & Graphics**: Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`), Postprocessing
- **Motion & UI**: Framer Motion, Modern CSS Glassmorphism
- **Fonts**: Oxanium, Space Grotesk, IBM Plex Mono, Inter

---

## 🌌 Key Highlights & Features

- **Kinetic 3D Hero Experience**: Interactive spatial WebGL visuals and scroll-reactive Black Panther camera sequence.
- **Kimoyo Tactical Skills Dock**: Multi-zone capabilities layout with tech brand dock and dual-tone cyber matrix.
- **Featured Projects Grid**: Clean 3x2 tactical cards featuring flagship projects (*Vaulta*, *Migration Master*, *DevLens*, *Agremate*, *RTGS/NEFT Banking*, *3D Portfolio*).
- **Vibranium Glassmorphism**: High-saturation frosted glass with specular borders, multi-angle chamfers, and reactive purple/cyan neon glow.
- **Single-Viewport Precision**: Calibrated 100vh layout with zero awkward scrolling and seamless atmospheric vignettes.
- **Tactical Audio & Pointer**: Custom Wakanda cursor and subtle high-tech sound feedback.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/black-panther-portfolio.git
cd black-panther-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
